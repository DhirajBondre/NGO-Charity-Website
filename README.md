# NGO-Charity-Website

Compassionate Connect – HelpBridge NGO Charity Management System

Compassionate Connect (HelpBridge) is a modern web-based NGO Charity Management System developed to connect donors, volunteers, and charitable organizations on a single platform.

Features
Fundraising campaign management
Real-time donation tracking
Volunteer registration system
Admin dashboard with CRUD operations
PDF donation receipt generation
Dark / Light mode support
Responsive design for mobile & desktop
Tech Stack
React.js
TypeScript
Vite
Tailwind CSS
Shadcn UI
React Router DOM
Zod Validation
jsPDF
Framer Motion
Purpose

This project aims to provide a transparent, user-friendly, and scalable digital solution for NGOs to manage campaigns, donations, and volunteers efficiently.

Future Enhancements
Payment gateway integration
Backend database support
User authentication
Email notifications
Mobile app support
